# FLASED

FLASED is a mobile flashcard app built for active recall. Generate flashcards from your notes using AI and review them with an adaptive study system.

**Repository:** [github.com/6sceed/Flased](https://github.com/6sceed/Flased?utm_source=chatgpt.com)
**Status:** In Development

## Features

* Generate flashcards with AI
* **BYOK (Bring Your Own Key)** — use your own Gemini or OpenRouter API key
* Gemini API recommended
* First-letter mnemonic codes
* Organize cards by Subjects and Modules
* Edit, add, and delete cards
* Track AI API usage
* Dark-themed mobile interface

## API Providers

* **Google Gemini** — recommended
* **OpenRouter** — alternative with access to multiple AI models

## Setup

```bash
git clone https://github.com/6sceed/Flased
cd Flased
npm install
npx expo start
```

Open the project with **Expo Go** on your phone.
